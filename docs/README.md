# זיכרון הפרויקט

התיקייה הזו היא מקור האמת של פרויקט מערכת ניהול העבודה.

בכל תחילת עבודה יש לקרוא, לפי הסדר:

1. `PRODUCT_PLAN.md` — מטרת המוצר, היקף העבודה ותוכנית הביצוע.
2. `DECISIONS.md` — החלטות שכבר התקבלו והנחות זמניות.
3. `STATUS.md` — המצב הנוכחי והפעולה הבאה.
4. `OPERATIONS.md` — פריסה, בדיקות בריאות, גיבוי, ניטור ונסיגה.

כללי תחזוקה:

- מעדכנים את `STATUS.md` בסיום כל שלב משמעותי ולפני עצירת עבודה.
- החלטת מוצר או החלטה טכנית משמעותית מתווספת ל־`DECISIONS.md`.
- שינוי בהיקף או בתוכנית הכוללת מתעדכן ב־`PRODUCT_PLAN.md`.
- אין לסמן שלב כהושלם לפני שנבדק בפועל.
